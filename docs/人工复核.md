# 人工复核（无 AI）

书扫通不接 AI，也不让规则静默改文档。机器只产出**候选**，人看完原图后决定
接受 / 拒绝 / 修正；只有已决定项会在下一次导出时生效。

## 1. 生成复核包

```powershell
.venv\Scripts\python.exe cli.py --pdf 书.pdf --review-out .\复核
```

目录内：

```text
复核/review.json       待决定项
复核/review.html       可离线打开的复核页
复核/review_assets/    每项的页面裁剪
```

打开 `review.html`，逐项看原图裁剪：

- **接受**：采纳机器当前值；
- **拒绝**：不采纳；
- **采纳修正**：用输入框里的值替换；
- 最后点“导出 review.json”。

没有“全自动改文档”，也没有 AI 接口。

## 2. 应用决定

```powershell
.venv\Scripts\python.exe cli.py --pdf 书.pdf --review .\复核\review.json
```

日志会打印：

```text
人工复核：采纳 3 项，跳过 0 项
```

只应用 `accepted` / `edited`；`pending` 不动。拒绝整页截图目前只会记日志，
因为导出器还没有去掉该页图的路径。

## 3. 候选类型

| kind | 含义 | 可执行 |
|---|---|---|
| `missing_line` | 源行没有进入任何 block | 接受/修正后补成正文块 |
| `low_conf_block` | 低置信度文字块 | 接受原值或替换 |
| `page_fallback` | 整页截图 | 可接受/拒绝；拒绝暂不自动去图 |

## 4. 数据形状

```json
{
  "review_version": 1,
  "source": "书.pdf",
  "items": [{
    "id": "p3m1",
    "kind": "missing_line",
    "page": 3,
    "bbox": [x0, y0, x1, y1],
    "proposed": "表1 ...",
    "confidence": 0.0,
    "reason": "filtered_or_unmatched",
    "status": "accepted",
    "human_value": null,
    "asset": "review_assets/p3m1.png"
  }]
}
```

## 5. 边界

- 不建数据库，`review.json` 就是账本；
- 不做多用户/云端；
- 不接 AI；以后如果接，AI 也只能写同一份 proposal，不能直接改 Word；
- 复核项来自 IR 的 `missing` / `fallback` / 低置信度，不是全篇每一字。
