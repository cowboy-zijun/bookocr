# 书扫通 BookOCR 方法说明

> 本文档描述软件各环节的设计思路、可靠性机制与已知局限，供使用者、
> 开发者与评审者参考。所有方法均基于公开开源组件实现，不依赖训练数据。

## 0. 总览

输入：扫描版 PDF（通常为超星/读秀等平台的黑白位图扫描件，无文字层）。
输出：按原书分页的 Word 文档（简体、可疑字标红、可选的权威文本校正）。

流程：**多路识别 → 版面重建 → 双栏纠错 → 权威对齐（可选）→ 导出**。
贯穿全流程的两个设计原则：

1. **不臆造**：任何一步都不"猜着改"。识别不确定的字只标记不改写；
   对齐只在相似度达标时替换；没有权威文本时不校正。
2. **可中断可追溯**：每页识别结果即写即存，中断后续跑；每次替换都基于
   逐字匹配，来源可查。

## 1. 三路交叉识别与可疑字标记

### 动机
单次 OCR 的错误无法自知。要获得"哪里可能错了"的信息，通常需要训练
置信度模型。本工具用更廉价的方式近似：**同一页的多份不同渲染**。

### 方法
对每页生成三份图：①原始二值图；②双倍插值放大图；③200dpi 灰度渲染图。
三份图分别送入同一识别模型（RapidOCR / PP-OCRv4 移动版），得到三组
文本行，按纵坐标对齐后**逐字投票**：

- 某字三路一致或有 2:1 多数 → 取多数
- 三路两两不同（1:1:1）→ 取最高置信度的一份，**该字标记为"可疑"**

导出时可疑字标红。实测此类模糊扫描件上，可疑字约占全文 0.1%–1%，
恰好对应"最可能出错处"，供用户重点核对。

局限：三路**同时错成同一个字**的错误无法被标记（这是任何无外部参照
方法都无法避免的）。

## 2. 版面重建

OCR 只给出"行"，需要恢复段落结构。使用的启发式（均基于扫描版图书的
一般排版规律）：

- 段首缩进：行首 x 坐标超出正文左边距 1.2 个字号以上 → 新段落
- 短行结尾：上一行右侧留白超过 1.6 个字 → 段落结束
- 居中 + 短行 + 无句末标点 → 标题
- 大量含"……"引导点且行尾是数字的页面 → 目录页，逐行成条
- 顶部反复出现的相同文字（书眉）与纯数字页脚 → 剔除

## 3. 双栏页自动纠错

### 问题
书末索引常为双栏小字。整页识别时，检测器会把左右两栏同一高度的行
配错（表现为"同一句出现两次""两栏内容交错"）。

### 方法
1. **检测**：以 40px 为带宽统计页面中部的文字覆盖率；双栏页在左右两栏
   之间存在一条"低覆盖率走廊"。要求该区域覆盖率低于整页 10%，且左右
   两侧各有 5 行以上、跨越中缝的行不超过 3 行（排除目录页"标题…页码"
   这类同行碎片的误判）。
2. **重排**：沿中缝把页面图切成两半，**各半单独重新识别**，输出顺序为
   左栏自上而下、再右栏自上而下——与图书的阅读顺序一致。
3. **成条**：索引条目跨多行，按"遇句号断条"规则合并；"X画"这类检索
   字头独立成条；纯数字页脚丢弃。

## 4. 权威文本对齐（可选）

### 前提
能找到**同一译本**的权威电子文本（如中文马克思主义文库收录的
《马克思恩格斯全集》中文版）。不同译本、不同版本不能直接对齐。

### 方法
1. **单调指针 + 局部模糊比对**：从权威文本开头出发，对每个 OCR 段落，
   在其后的 9000 字符窗口内做 partial_ratio 比对，取最优子串。相似度
   阈值按段落长度分档（短段 84、中段 78、长段 72——长段随机撞对的
   概率极低，可放宽）。达标即以权威原文替换该段。
2. **覆盖率守卫**：记录每个已输出的权威文本区间；候选匹配若与已输出
   区间重叠超过 75% 即判为重复丢弃。这一步防的是"前一段匹配越界、
   后一段重复输出"。
3. **第二遍：拼段重试**：OCR 常把一段拆成多行，各片单独相似度不足。
   把连续未匹配的片段拼接后重试，命中即以权威原文整体替换。
4. **第三遍：全局检索**：对仍未匹配的段落，用 12 字 k-mer 索引在全文
   检索。已出现过（如内联脚注）→ 判重丢弃；新内容 → 采用权威原文。

### 可靠性指标
在一次 738 页的真实案例中：权威文本按序覆盖 99.8%（无系统性漂移），
约 89% 的正文与权威文本对齐；未对齐部分为原书页脚编者注、书末注释
与人名索引（权威文本未收录）。

## 5. 断点续跑

- 每个识别进程写独立分片文件，**每页完成立即 flush 落盘**
- 重启时读取已有页号，跳过已完成页
- "暂停"是协作式的：进程在当前页结束后退出，不产生半页脏数据
- 因此任务可在任意时刻安全中断（断电除外——仅影响最后一页）

## 6. 导出排版

- **先量框，再排版**：从 PDF 的行框统计出这本书的纸张（页面尺寸众数）、
  左右边距（正文行起点 5% / 行末 95% 分位）、上下边距（每页首行/末行
  的中位数）、正文字号（按字数加权中位数）、行距（相邻正文行间距的
  中位数）和字宽；在 Word 里用同一套厘米/磅值 1:1 复排。量出的框先过
  合理性闸门（边距非负、版心占比、字号 5–24 磅、行距 1–2.6 倍），
  不合理就退回默认 32 开并在日志里写明原因
- **一页对一页**：每页强制分页，Word 第 N 页 = 原书第 N 页；页码行用
  图文框钉在页面上（原书页眉所在高度），不占正文高度，正文从真正的
  版心上沿开始
- 标题字号直接取原书实测字号分档，不再用"正文 + 固定磅数"推断
- **图文先量后插**：图片按原书矩形同时给出宽和高，图下的正文紧接着排；
  表格同样"先量框"：文字层 PDF 直接读矢量框线，扫描页从页面图像里量
  横/竖线；都没有时退回按列对齐和数字规律。量到几列几行就还原成 Word
  真表格，合并单元格、按原书列宽排，表题用单倍行距，表下的正文不会被
  挤到下一页
- 表格识别分三层：矢量框线 → 扫描图像框线 → 文字对齐；扫描件的格子
  文字会按格再 OCR 一遍，避免整页 OCR 把相邻两格读成一行、文字串列
- 无框文字表最后过一道"语法审查"（只否决，不正向识别）：区域铺满版心、
  双栏连续正文、格内句末标点多、相邻行能接成一句话、格子文字过长、
  没有表题且首行不像短表头——命中任意一条就按正文保留；有表题/表头、
  行独立、列平行的才还原成表格
- **论文/期刊模式**（界面"文档类型"或 `--mode paper`）：先做页面分区
  （递归 XY 切割：页眉页脚 → 横线/大空白 → 栏中缝 → 字号突变），给区域
  贴"题名/摘要/元数据/正文/参考文献/他文续文"标签，再按标签整合：第 1 页
  标题、摘要、作者、基金、中图分类号按单栏通栏排，正文切双栏；后续页
  保持双栏；"参考文献/注释"按注文小字排；"（上接第X页）"的另一篇文章
  续文整块剔除
- Word 的中文断行比原书保守（每行少排约一个字），排不下时依次：
  字符横向收紧（字号不变）→ 压行距 → 缩该页字号
- 层级：黑体标题、宋体正文、楷体小字注文与索引、权威文本内联脚注
  （［注：…］）以小号蓝色楷体呈现

## 7. 与既有方法的关系（诚实定位）

- 多假设识别 / 集成（ensemble）、OCR 后处理（post-correction）、
  多栏版面分割均为文献中已有方向；本工具未提出新理论
- 本工具的价值在**零训练、全公开组件、可完全复现的流程集成**，以及
  若干工程性设计：廉价的三渲染置信度近似、同译本对齐 + 覆盖率守卫、
  协作式中断的续跑机制
- 可能的深化方向：利用三路分歧数据训练轻量纠错模型；把"同译本对齐"
  扩展到更多类型的权威电子文本；把双栏检测推广到表格与混合版式

## 8. 局限

1. 无权威文本时，正文错字率约 2%–4%，红字为高概率可疑处而非全部
2. 人名索引的小字双栏经重排后，个别条目仍可能有缺字
3. 权威对齐要求同一译本；不同译本语义相近但字面不同，阈值不达标
   时会保留 OCR 原文而非强行替换
4. 段落重建依赖印刷图书的排版规律，对杂志、报纸、批注密级页效果有限
